# Ship2Aruba Design System

## Brand
- Name: Ship2Aruba
- Tagline: "Fast, reliable shipment management"
- Vibe: Modern SaaS, enterprise logistics, professional, trustworthy

## Colors
- Background: #FFFFFF (light mode), sidebar: #0F1117 (dark sidebar always)
- Primary accent: #F97316 (orange-500) — buttons, badges, CTAs
- Text primary: #111827
- Text secondary: #6B7280
- Border: #E5E7EB
- Success: #22C55E
- Warning: #EAB308
- Danger: #EF4444
- Info: #3B82F6
- Card background: #F9FAFB
- Sidebar active bg: rgba(249,115,22,0.15)

## Typography
- Font: Poppins (Google Fonts)
- Display: Poppins 700-800
- Headings: Poppins 600
- Body: Poppins 400
- Mono: JetBrains Mono (tracking numbers)

## Spacing
- Sidebar width: 240px
- Content padding: 32px
- Card padding: 24px
- Border radius: 12px (cards), 8px (buttons), 6px (badges)

## Components
- Sidebar: dark (#0F1117), white icons, orange active state
- Cards: white, 1px border, subtle shadow
- Status badges: pill shape, colored bg+text
- Tables: clean white, hover highlight, sortable headers
- Buttons: orange primary, ghost secondary
- Forms: clean inputs, orange focus ring

## Status Colors
- uploaded: blue
- pending_review: yellow/amber
- approved: green
- rejected: red
- shipment_requested: purple
- shipped: teal/cyan
